# database

The `database` slot (`DatabaseSlotV1`): `db()` over `pg`, PGlite served by `revbound dev` when `DATABASE_URL` is unset, every plugin's migrations and the company's, the production stamp, the destructive-migration rule, the Data view and Open database (local, and shared with your own Tailscale login).

- Line budget: 1,350 lines of TypeScript (`npm run lines` in the revbound repository), reviewed at every release.
- Commands and docs: `revbound migrate`; docs: `data`.
- Eject it with `npx revbound eject database` to edit a copy in `plugins/database/`; `npx revbound diff database` shows upstream changes.
