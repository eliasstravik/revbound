# mdm

The `mdm` slot (`MdmSlotV1`), optional: one de-duplicated set of people, companies and signals, matched on their keys,
with where every field came from; merging; `#revbound/mdm`; and the People, Companies and Signals views.

- Add it with `npx revbound add mdm`; it is not one of the defaults.
- Line budget: 850 lines of TypeScript (`npm run lines` in the revbound repository), reviewed at every release.
- Docs: `mdm`; skill: `mdm-records`.
- Eject it with `npx revbound eject mdm` to edit a copy in `plugins/mdm/`; `npx revbound diff mdm` shows upstream
  changes.
